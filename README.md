# Portail Web POINFOR x GTLA

Portail web officiel de transmission sécurisée des dossiers de formation pour le centre **POINFOR**, développé par **GTLA**.

## Architecture & Fonctionnement
- **Interface Web 24h/24 :** Permet au commanditaire de déposer son archive ZIP de stagiaires et de renseigner son email professionnel.
- **Stockage sécurisé :** Les dossiers sont enregistrés en attente de traitement par le moteur d'IA local.
- **API Sécurisée :** L'agent IA local interroge le portail pour récupérer automatiquement les dossiers dès son allumage.
- **Hébergement :** Prévu pour être déployé sur Render ou Vercel sous le sous-domaine `poinfor.gtla.fr`.
